# 손 사진 출처 (합성 시험용)

- 내려받은 날: 2026-11-12. 위치: `work/openkey-live/hands/`(**저장소 밖**, `work/`는 커밋 제외). Wikimedia Commons API의 900px 미리보기(thumb)를 받았다. 메타데이터 원본: `work/openkey-live/hands/sources.json`.
- 용도: kiosk-host 화면 캡처 위에 잘라 붙여 손 인식 경로를 시험하는 데만 썼다(합성 프레임은 메모리에서만 만들고 저장하지 않음). 모델 학습·배포·발표 자료에 쓰지 않았다. CC BY-SA 사진을 저장소에 넣거나 배포하려면 저작자 표시·동일 조건 변경 허락을 지켜야 한다.
