# OpenKey 시연
기존 키오스크에 붙이는 AI 손끝 안내 장치의 시연 프로그램. 휴대폰 카메라가 키오스크 화면과 손끝을 보고, 원하는 버튼까지 음성으로 안내한다. **누르는 것은 사용자 본인이다.**
 

## 처음 한 번

1. 이 저장소를 받는다: `git clone <이 저장소 주소>`.
   - 폴더 경로에 한글이나 공백이 없는 곳을 권장한다. 있어도 동작하도록 우회해 두었다.
2. **`환경-설치.bat`** 을 더블클릭한다. 파이썬 가상환경 `.venv`, 패키지, 시연용 인증서를 한 번에 준비한다.
   - Python 3.12 이상이 필요하다.
   - 인증서는 Git for Windows에 들어 있는 openssl로 만든다.

## 상태와 원칙

- **상태(2026-11-12)**: PC 가상 시험은 통과했다. 팀원이 실제 휴대폰으로 시험해 손 인식은 잘 됐다. 실제 사용자 시험은 아직이다.
- **버튼 위치**: 모의 키오스크가 알려 주는 시연용 정답 좌표다. 카메라 OCR은 연결하지 않았다.
- **기록**: 영상·사진·음성은 저장하지 않는다. 좌표·시간·안내 문구만 `07-demo/openkey-live/runs/`에 남는다. 연습·실제 기록은 저장소에 올리지 않는다.
- **올리지 않는 것**: `.venv/`, `work/`(인증서 등).
